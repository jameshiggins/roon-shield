# roon-shield

A native Android TV app for the **Nvidia Shield** that acts as a **Roon remote**, redesigned for the
Shield game controller / D-pad. It controls existing Roon output zones via Roon's official
**Extension API** (WebSocket + MOO protocol) — browse, search, now-playing, transport, and queue.

> **Scope note:** This is a *control-only* remote for existing Roon endpoints. It cannot make the
> Shield itself a Roon playback zone (that requires RAAT / "Roon Ready," which is partner-only and not
> in the public API).

See [`PLAN.md`](./PLAN.md) for the full implementation plan.
